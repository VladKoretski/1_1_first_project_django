# Домашнее задание: Знакомство с Django

Простой учебный Django-проект, демонстрирующий базовую настройку маршрутизации (URLs) и работу с представлениями (Views).

## 📋 Описание задания
В рамках задания необходимо было реализовать три view-функции и настроить для них правильные URL-маршруты:
1. **Главная страница** (`/`) — выводит список доступных страниц с помощью шаблона и функции `reverse`.
2. **Текущее время** (`/current_time/`) — отображает текущее время сервера.
3. **Рабочая директория** (`/workdir/`) — выводит список файлов и папок, находящихся в корневой рабочей директории проекта.

## 🛠️ Стек технологий
*   Python 3.12
*   Django 6.1.2 *(версия может отличаться, в зависимости от вашего окружения)*

## 🚀 Как запустить проект

Для запуска проекта на локальной машине выполните следующие шаги:

### 1. Клонирование репозитория
Скачайте проект и перейдите в его корневую папку (там, где находится файл `manage.py`).

### 2. Создание и активация виртуального окружения
Рекомендуется использовать виртуальное окружение для изоляции зависимостей:
```bash
python -m venv venv
```
# Активация (Windows)
```bash
.\venv\Scripts\activate
```
# Активация (macOS/Linux)
```bash
source venv/bin/activate
```
3. Установка зависимостей
Установите все необходимые библиотеки из файла requirements.txt:
```bash
pip install -r requirements.txt
```
4. Запуск сервера
Запустите локальный сервер разработки:

```bash
python manage.py runserver
```
После успешного запуска сервер будет доступен по адресу: http://127.0.0.1:8000/

## Структура и реализация
Основная логика находится в приложении app:
* app/views.py — содержатся функции home_view, time_view и workdir_view.
* Для работы с файловой системой используется стандартный модуль os (функции getcwd() и listdir()).
* Для получения времени используется модуль datetime.
* Страница workdir/ возвращает ответ с content_type='text/plain', чтобы переносы строк \n корректно отображались в браузере.
* app/urls.py (и главный urls.py проекта) — настроены маршруты для корректной обработки запросов.
